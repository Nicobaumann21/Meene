## 3.3.2 Begründung der Kernkomponenten

### Apache Spark mit MLlib

Spark wurde gewählt, weil:

- **Verteilte Verarbeitung**: Auch wenn die VM nur ein Single-Node-Setup ist, partitioniert Spark die Daten auf alle 4 vCPUs und nutzt sie parallel — bei 647 MB `ratings.csv` essenziell.
- **MLlib-ALS**: Spark MLlib enthält eine produktionsreife Implementierung des **Alternating Least Squares**-Algorithmus für Collaborative Filtering. ALS ist der Standardansatz für Matrixfaktorisierung auf großen, dünnbesetzten User-Item-Matrizen.
- **DataFrame-API**: Bietet SQL-ähnliche Operationen (`select`, `filter`, `dropna`) und automatische Optimierung (Catalyst Optimizer).
- **Speichermanagement**: Spark spillt automatisch auf Disk, wenn der Arbeitsspeicher nicht ausreicht — wichtig bei nur 8 GB RAM und 25M Zeilen.

### Python + PySpark

- **PySpark** ist die offizielle Python-API für Spark. Sie ist funktional äquivalent zur Scala-API, aber im akademischen Umfeld deutlich verbreiteter.
- **Version 3.5.0** wurde gewählt, weil sie die zum Projektstart aktuellste stabile Spark-Version war und mit Java 17 sowie Python 3.10+ kompatibel ist.

### Java 17

- Spark 3.5 unterstützt offiziell Java 8, 11 und 17. **Java 17** ist die aktuellste der LTS-Versionen und wird von beiden Zielsystemen (macOS via Homebrew, Ubuntu via apt) als Paket angeboten.

### Pandas / Matplotlib

- Spark-DataFrames eignen sich für Massenverarbeitung; für die finale Auswertung (z. B. die Top-10-Empfehlungen pro Nutzer) ist die Konvertierung nach Pandas (`toPandas()`) bequemer.
- **Matplotlib** wird für die Visualisierung der Bewertungsverteilung und Modellgüte (RMSE, Genauigkeit) eingesetzt.

### Jupyter Notebook

- Erlaubt interaktives Experimentieren mit Spark, ohne den vollen JVM-Startup bei jedem Skriptaufruf.
- Mit SSH-Port-Forwarding lässt sich der auf der VM laufende Notebook-Server bequem im lokalen Browser bedienen.

## 3.3.3 Verworfene Alternativen

| Alternative          | Verworfen, weil …                                                                |
|----------------------|----------------------------------------------------------------------------------|
| `scikit-learn` allein| Skaliert nicht auf 25M Zeilen; kein verteiltes Collaborative Filtering           |
| `surprise`-Library   | In-Memory-only, würde bei 25M Zeilen auf 8 GB RAM ausfallen                      |
| TensorFlow Recommenders | Overkill für klassisches Collaborative Filtering; deutlich höhere GPU-Anforderungen |
| Dask                 | Weniger ausgereifte ML-Bibliothek als Spark MLlib                                |

## 3.3.4 Reproduzierbarkeit

Die Wahl der Komponenten ist bewusst konservativ: Alle Werkzeuge sind frei verfügbar, gut dokumentiert und werden in der Lehre eingesetzt. Eine vollständige Installationsanleitung mit Versionsangaben findet sich in [`docs/setup.md`](setup.md) (Kapitel 4.1).
